# 🔍 Módulo — SEO y Contenido

## ENTENDER
Optimización para motores de búsqueda: metadatos, Schema.org, redirecciones, blog y sitemap.

## PENSAR
Tablas: `metadatos_seo`, `redirecciones`, `publicaciones_blog`

## Funcionalidades
- [ ] Metadatos SEO por página (título, descripción, OG, Twitter)
- [ ] Schema.org (JSON-LD) para productos
- [ ] Sitemap XML automático
- [ ] Robots.txt configurable
- [ ] Redirecciones 301/302 desde el admin
- [ ] Blog para contenido SEO
- [ ] URL canónicas
- [ ] Breadcrumbs estructurados
- [ ] Auditoría SEO básica integrada

## Campos SEO por Entidad
- Productos: título H1, meta título (70 chars), meta descripción (160 chars)
- Categorías: igual + descripción larga
- Blog: título, descripción, imagen OG, etiquetas
- Páginas: configuración manual completa
